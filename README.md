# 🏥 Sistema de Gestão de Clínica Médica

Sistema web desenvolvido como projeto acadêmico para gerenciamento de atendimento em clínicas médicas. A aplicação permite realizar cadastros de pacientes e médicos, além de gerenciar a agenda de consultas em um banco de dados relacional.

## 🚀 Tecnologias Utilizadas

- **Backend:** Python 3 + Flask
- **Banco de Dados:** SQLite
- **ORM:** SQLAlchemy
- **Frontend:** HTML5, CSS 

## 📌 Funcionalidades

- **Módulo de Pacientes:** Cadastrar e remover pacientes com validação de CPF.
- **Módulo de Médicos:** Cadastrar e remover médicos com registro de CRM.
- **Módulo de Agendamentos:** Marcar e cancelar consultas com seleção visual de data e horário.
- **Arquitetura Modular:** Separação de rotas, banco de dados e templates herdados (`base.html`).
